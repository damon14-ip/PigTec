# PigTec

Sistema web para gestionar y consultar los registros de produccion porcina de la granja KolkaPig.

## Objetivo

Organizar los registros de animales, movimientos, sanidad, reproduccion e inventario, y facilitar su consulta y trazabilidad.

## Arquitectura prevista

- frontend: React, TypeScript y Vite.
- backend: Node.js, TypeScript y Fastify.
- base de datos: PostgreSQL mediante Supabase.
- control de versiones: Git.
- asistente IA: consultas de solo lectura mediante el backend.

## Estado

Fase inicial: preparacion del entorno y organizacion del proyecto.

## Seguridad

No guardar contrasenas, claves API, tokens ni archivos `.env` reales en Git.
